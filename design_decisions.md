## Типографика

**КРИТИЧНО:** убираем Fraunces. Connecterra использует **только sans-serif**.

### Семейства
- **Основной и заголовки:** Inter (400, 500, 600, 700)
- **Моноширинный:** JetBrains Mono (только для ID, timestamps, технических значений)

НЕТ серифного шрифта. Всё в одном семействе.

### Размеры
- `text-xs: 11px` — метки, маленькие badges
- `text-sm: 13px` — вторичный текст, метки карточек
- `text-base: 14px` — основной текст (НЕ 16px — Connecterra более плотный)
- `text-md: 15px` — заголовки карточек
- `text-lg: 18px` — подзаголовки секций ("Latest on your farm")
- `text-xl: 22px` — заголовки страниц ("Good morning, Андрей!")
- `text-2xl: 28px` — hero-цифры в KPI
- `text-3xl: 36px` — главное приветствие

### Веса
- 400 regular — body
- 500 medium — labels
- 600 semibold — заголовки карточек и страниц
- 700 bold — hero

### Line-height
- `leading-tight: 1.2` — заголовки
- `leading-normal: 1.5` — body
- `leading-relaxed: 1.7` — длинные параграфы (insight descriptions)

## Скругления и тени

- `--radius-sm: 4px` — badges, small chips
- `--radius: 6px` — карточки (важно: **не 12-14px** как я раньше говорил, Connecterra более скромный)
- `--radius-lg: 8px` — modals
- `--radius-pill: 999px` — pills, attention badges

### Тени (очень деликатные)
- `--shadow-none: none` — по умолчанию карточки без тени
- `--shadow-sm: 0 1px 2px rgba(0,0,0,0.04)` — тонкая
- `--shadow: 0 1px 3px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)` — карточки (edge border + small shadow)
- `--shadow-lg: 0 4px 16px rgba(0,0,0,0.08)` — modals, dropdowns

Связка: **border + лёгкий shadow**, как у Connecterra. Не glow, не gradient, не floating.

## Motion (минимальный)

Connecterra почти **не анимирует**. Только стандартные hover-transitions и page-load. Заметно сдержаннее, чем я предлагал раньше.

- `--duration-fast: 120ms` — hover color transitions
- `--duration-base: 200ms` — component mount/unmount
- `--ease-standard: cubic-bezier(0.2, 0, 0.38, 0.9)`

### Что НЕ делаем (чтобы не выбиваться из Connecterra-стиля)
- ❌ Number counter animation (0 → 100)
- ❌ Parallax
- ❌ Shimmer/glow effects
- ❌ Complex page transitions
- ❌ Staggered entrance

### Что оставляем
- ✅ Hover color transition (кнопки, nav-links)
- ✅ Dropdown/Tooltip fade-in
- ✅ Modal/Drawer slide-in
- ✅ Skeleton loaders (статичные grey blocks)

## Русский копирайтинг — принципы

- Обращение: **"вы"** с маленькой буквы (Connecterra: "Good morning, Андрей!" → "Доброе утро, Андрей!")
- Глаголы в действительном залоге
- Числа: 1 234,56 (пробел тысячи, запятая десятичные)
- Даты короткая: "11 марта 2026"
- Даты полная: "11.03.2026 14:32"
- Избегать англицизмов там, где есть русский эквивалент:
  - "дашборд" → "обзор" или "панель"
  - "эдит" → "редактировать"
  - "прогресс" → "процесс" или "ход"
- Но сохранить:
  - Инсайт, Помощник (Copilot), Лента событий
  - Проф-термины: SCC, THI, DMI, ECM, DIM, NPV, BCS

### Шаблоны фраз (для консистентности)
- Пустое состояние "всё ок": "Всё под контролем. Ничего срочного."
- Attention pill: "Требует вашего внимания"
- Результаты после события: "Результаты готовы"
- Демо-баннер: "Это демо-ферма с тестовыми данными. Она показывает, что приложение делает, как только ваши данные будут подключены."

## Mobile стратегия (ПЕРЕСМОТР)

**Нативный Android ❌ — не успеть за месяц.**

**PWA (Progressive Web App) ✅ — реалистично.**

Мобильный опыт в MVP = responsive web_app + PWA-манифест:
- responsive layout с breakpoints 640/768/1024/1280
- На мобильном sidebar превращается в bottom tab bar (5 пунктов)
- Service Worker для basic offline (последние просмотренные страницы)
- Add to Home Screen манифест (иконка, splash screen)
- Touch-friendly тапы (минимум 44×44 px)
- FAB для добавления событий в углу

**Demo-ready: пользователь открывает URL на телефоне → `Add to Home Screen` → выглядит как приложение.**

Connecterra на самом деле именно так и работает. Посмотри их скриншоты: никакой магии, это web с responsive.

Нативное Android-приложение остаётся в roadmap как Фаза 2 (после показа), использует `mobile_android/` foundation из репо.
