# Starter support records

Эти записи предназначены только для runnable validation T31-03.
Они **не являются evidence** реальной клиентской поддержки, SLA или incident history.

Runtime-контур пишет рабочие записи в `web_storage/support/support_operating_records_v1.json`,
не изменяя starter-файл под `data/support/`.
