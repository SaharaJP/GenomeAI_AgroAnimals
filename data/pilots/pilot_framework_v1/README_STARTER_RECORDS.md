# Pilot framework starter records

Этот каталог содержит **starter/sample** записи для проверки pilot framework и reference deployment contour.

Важно:
- это **не evidence реальных внедрений**;
- записи нужны для runnable validation, smoke и UI-preview;
- referenceable deployment по умолчанию должен оставаться `false`, пока не приложено явное field evidence.
