# Документация для пилотной фермы — GenomeAI

Добро пожаловать в систему **GenomeAI AgroAnimals** — цифровой помощник для управления молочным стадом.

В этой папке собраны пошаговые инструкции, которые помогут вам начать работу с системой: подготовить данные из вашей текущей программы учёта, войти в GenomeAI и узнать, какие задачи ИИ-ассистент поможет решать каждый день.

Инструкции написаны простым языком — без лишних технических терминов. Если что-то непонятно, обращайтесь на support@genomeai.ru.

---

| Файл | Что описывает | Для кого |

| `01_csv_export_dairycomp_305.md` | Как выгрузить данные из программы DairyComp 305 (DC305) | Зоотехник, работающий с DC305 |
| `02_csv_export_selex.md` | Как выгрузить данные из программы Селекс | Зоотехник, работающий с Селекс |

| `05_what_ai_can_help_with.md` | Список задач, с которыми помогает ИИ-ассистент | Зоотехник, ветеринар, руководитель |

---

## Рекомендуемый порядок действий

1. Определите, какая программа учёта используется на вашей ферме (DC305, Селекс или 1С: Селекция).
2. Прочитайте соответствующую инструкцию по экспорту (файлы 01, 02 или 03) и выгрузите данные в формате CSV.
3. Прочитайте инструкцию по первому входу (файл 04) и загрузите данные в систему.
4. Ознакомьтесь с возможностями ИИ-ассистента (файл 05), чтобы знать, о чём спрашивать систему.
