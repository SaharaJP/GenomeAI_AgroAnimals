# Экспорт данных из Селекс

**Для кого:** зоотехник или оператор, работающий с программой Селекс (Seleks).

**Что нужно сделать:** выгрузить данные о животных в формате CSV или Excel, чтобы загрузить их в систему GenomeAI.

**Применимо к версиям:** Селекс версий 7.x и 8.x. В версиях 5.x и 6.x путь к меню может отличаться — см. раздел «Если у вас старая версия» в конце этой инструкции.

---

## Шаг 1. Запустите программу Селекс

1. Дважды щёлкните ярлык **Селекс** на рабочем столе или в меню «Пуск».
2. Введите логин и пароль.
3. В верхней части экрана должно быть видно название вашего хозяйства.

> Скриншот будет добавлен на Неделе 5: главный экран Селекс

---

## Шаг 2. Откройте раздел «Выгрузка данных»

1. В главном меню слева или вверху найдите раздел **Сервис** или **Инструменты**.
2. В нём выберите **Выгрузка данных** или **Экспорт**.

Альтернативный путь (в некоторых сборках):
- Главное меню → **Отчёты** → **Выгрузка в файл**.

> Скриншот будет добавлен на Неделе 5: меню выгрузки Селекс

---

## Шаг 3. Выберите вид данных

Для GenomeAI нужно выгрузить несколько разделов:

| Раздел | Что выбрать | Что содержит |
|---|---|---|
| Поголовье | **Животные** или **Карточки животных** | идентификаторы, породы, группы |
| Молочная продуктивность | **Контрольные дойки** или **Удои** | дата, животное, удой, SCC, жир, белок |
| Воспроизводство | **Осеменения** и **Отёлы** | даты, результаты |
| Здоровье | **Болезни** или **Ветеринарные мероприятия** | диагнозы, лечения |

Выгружайте каждый раздел отдельно.

---

## Шаг 4. Настройте параметры выгрузки

1. Укажите **период**: с **01.01.2023** по сегодняшнюю дату (или по согласованию с менеджером GenomeAI).
2. В поле **Формат файла** выберите **CSV** (предпочтительно) или **Excel (.xlsx)**.
3. Разделитель полей: выберите **точку с запятой (;)** — это стандарт для русскоязычного Excel и Селекс.
4. Кодировка: если есть выбор, укажите **Windows-1251** (стандарт для Селекс) или **UTF-8**.
5. Нажмите **Выгрузить** или **ОК**.

> Скриншот будет добавлен на Неделе 5: настройки формата и разделителя

---

## Шаг 5. Сохраните файл

1. Откроется окно выбора папки.
2. Сохраните файл в удобное место, например: **Рабочий стол** → **GenomeAI_данные**.
3. Дайте понятное имя: `молоко_Заря_2024.csv`.
4. Нажмите **Сохранить**.

Повторите для каждого раздела данных.

---

## Если у вас старая версия Селекс (5.x или 6.x)

В старых версиях путь к экспорту может быть другим:

- **Версия 5.x:** Главное меню → **Файл** → **Экспорт** → выбрать таблицу.
- **Версия 6.x:** Главное меню → **Администрирование** → **Выгрузка**.

Если вы не можете найти функцию экспорта — обратитесь к системному администратору или в техническую поддержку разработчика Селекс.

---

## Частые проблемы и решения

| Проблема | Что сделать |
|---|---|
| Кнопка «Выгрузить» недоступна | Нет прав. Попросите администратора Селекс добавить роль «Экспорт данных». |
| В файле CSV все данные в одной колонке | Разделитель выбран неправильно. Переоткройте файл в Excel: Данные → Текст по столбцам → Разделитель «точка с запятой». |
| Файл открывается с кракозябрами | Кодировка файла — Windows-1251. В Excel при открытии выберите «Кодировка файла» → Windows-1251 (ANSI). |
| Выгружается только часть животных | Проверьте фильтр по группе или статусу — снимите все ограничения. |
| Программа зависает | Уменьшите период: выгружайте по полгода. |
