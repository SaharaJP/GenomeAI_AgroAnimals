# T14-01 — шаг 3

## Что сделано
- Добавлен deep-link target для fact/table/source цитат в формате `genomeai://copilot/fact?...` с привязкой к `data_version`, `run_id`, `section`, `table`, `metric`, `report_version`, `fact_id`.
- Усилен LLM-режим: даже при `strict_source_only=false` ответ проходит обязательный post-validation по inline-цитатам и target-ссылкам.
- Если LLM вернул unsupported ответ без ссылок или со ссылкой на неподтверждённый факт, Copilot автоматически откатывается на deterministic source-only шаблон.
- Добавлен best-effort audit для событий `assistant.copilot.answer` и `assistant.copilot.llm_post_validate`.
- Расширен нижний блок `Источники/версии`: теперь там публикуется и `target=` для каждой citation.
- Добавлены тесты на deep links, post-validation и fallback без галлюцинаций.

## Что не покрыто этим шагом
- Web-cabinet ещё не превращает `genomeai://copilot/fact?...` в кликабельный экран с переходом на конкретную страницу run/table.
- LLM по-прежнему не используется в default strict-режиме; это намеренно, чтобы сохранить acceptance criteria на отсутствие unsupported claims.
