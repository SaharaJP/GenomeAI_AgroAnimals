# T7-01 — Экономика / what-if

## Цель
Дать директору прозрачные витрины экономики (выручка/затраты/маржа) и простой сценарный пересчёт: изменение цены молока и/или стоимости корма -> пересчёт маржи.

## Входные данные (Target v2)
Минимально необходимые:
- `dm_milkings_daily` (или fallback `dm_testday`): `tenant_id, animal_id, date, milk_kg`
- `dm_animals`: `animal_id, farm_id, current_pen_id`
- `dm_feed_deliveries`: `pen_id, ration_id, delivery_date, feed_kg_as_fed`
- `dm_feed_rations`: `ration_id, dm_pct`
- `dm_pens`, `dm_sites`: маппинги `pen_id -> farm_id`

Опционально (улучшает точность):
- `dm_pen_moves`: историческое определение `pen_id` для надоев по дате
- `dm_economics_daily`: цены/затраты по дню (`milk_price_per_kg`, `feed_cost_per_kg_dm`, `other_cost_eur`)
- `dm_prices`: fallback цены (в основном `milk`, по `valid_from/valid_to`)

## Периодичность обновления цен/затрат
Задаётся в `configs/economics/economics_v1.yaml` (для UI/документации):
- milk_price_update_period: monthly
- feed_price_update_period: monthly
- other_cost_update_period: quarterly

## Формулы
1) **Выручка** (farm-day или pen-day):
- `revenue = milk_kg * milk_price_per_kg`

2) **Корм**:
- `feed_dm_kg = feed_kg_as_fed * (dm_pct/100)`
- `feed_cost = feed_dm_kg * feed_cost_per_kg_dm`

3) **Прочие расходы** (farm-day):
- берём `dm_economics_daily.other_cost_eur` если есть
- иначе fallback `defaults.other_cost_per_farm_day` из конфигурации

4) **Распределение прочих расходов по группам (pen_id)**
Настраивается `allocation.other_cost_allocation`:
- `revenue_share` (по умолчанию): доля выручки группы в farm-day
- `headcount_share` (зарезервировано; будет корректно работать после добавления headcount по группе)

5) **Итог**:
- `total_cost = feed_cost + other_cost`
- `margin = revenue - total_cost`
- `margin_pct = margin / revenue` (если `revenue>0`)

## What-if
Сценарий задаётся мультипликаторами:
- `milk_price_multiplier`
- `feed_cost_multiplier`
- `other_cost_multiplier`

Пайплайн всегда пишет и **baseline** (1.0/1.0/1.0), и **scenario**.

## Артефакты
`artifacts/<data_version>/economics/<economics_run>/`:
- `farm_day_baseline.csv`, `farm_day_scenario.csv`
- `pen_day_baseline.csv`, `pen_day_scenario.csv`
- `summary_farm.csv`, `summary_pen.csv` (baseline vs scenario)
- `economics_whatif.xlsx`
- `whatif_params.json`, `manifest.json`, `checksums.json`

## UI
Streamlit страница: **Economics / What-if**.
UI запускает `genomeai.economics_whatif.run_economics_whatif(...)` и отображает/экспортирует результаты.
