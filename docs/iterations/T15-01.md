# T15-01 — Baseline + Golden set + verify_refactor

## Что добавлено
- `golden/` с двумя сценариями: `standard` и `qc_issues`.
- CLI `genomeai verify_refactor` и alias `genomeai verify-refactor`.
- Ручное обновление эталонов: `--update-golden --i-understand-update-golden`.
- Snapshot-сравнение по ключевым артефактам: `qc`, `score`, `report`, `fact_pack`, `decision_log`, `tasks`, `audit`.
- Markdown/JSON отчёт с diff по файлам.
- `golden/manifest.json` с sha256/size индексом inputs+snapshot для воспроизводимости baseline.

## Как запускать
```bash
pip install -e .
genomeai verify_refactor
```

## Что сравнивается
Сначала валидируется целостность самого golden через `golden/manifest.json`, затем сравниваются snapshot-файлы сценариев.

- `qc_summary.json`
- `scoring_summary.json`
- `scored_latest.csv`
- `fact_pack.json`
- `report_summary.json`
- `report_narrative.json`
- `decision_log.csv`
- `tasks.json`
- `audit.json`
- `artifact_presence.json`

## Обновление baseline
```bash
genomeai verify_refactor --update-golden --i-understand-update-golden
```

Обновление golden допускается только при сознательном принятии нового ожидаемого поведения.


## Step 3 — CLI shim -> application use-case
- Добавлен слой `src/genomeai/application/refactor_verify.py`.
- CLI `verify_refactor` больше не содержит orchestration-логику обновления/проверки; он только собирает `VerifyRefactorCommand`, вызывает use-case и печатает строки результата.
- Существующие низкоуровневые функции `genomeai.refactor_verify.verify_refactor/update_golden` сохранены без смены импорта для обратной совместимости.
- Добавлены тесты на парсинг `--scenarios` и блокировку `--update-golden` без явного подтверждения.
- Вынесен service-adapter `src/genomeai/application/refactor_verify_service.py`: use-case слой больше не вызывает legacy facade напрямую, но контракт `genomeai.refactor_verify.*` сохранён без изменений.


## Step 4 — compare/report split
- Добавлен слой `src/genomeai/application/refactor_verify_compare.py`.
- Туда перенесены dataclass-структуры verify-отчёта, сравнение snapshot-директорий, Markdown-render и JSON-serialization.
- `src/genomeai/refactor_verify.py` сохранил внешние функции `verify_refactor/update_golden`, но больше не содержит compare/report-детали.
- Добавлены тесты на missing/extra diff и стабильную сериализацию отчёта.

- Step 6: moved scenario selection and report-root orchestration into `application/refactor_verify_runtime.py`; kept `refactor_verify.py` as compatibility facade without changing CLI behavior.

- Step 7: результат выполнения (`VERIFY_REFACTOR_OK/FAILED/GOLDEN_UPDATED/UPDATE_BLOCKED`) и CLI-formatting вынесены в `src/genomeai/application/refactor_verify_result.py`; use-case orchestration сохранён в `src/genomeai/application/refactor_verify.py`, а низкоуровневый фасад — в `src/genomeai/refactor_verify.py`.
- Добавлены точечные тесты на рендер строк CLI для `GOLDEN_UPDATED` и `FAILED`, чтобы сохранить формат вывода без регрессий.


## Step 9 — exception mapping split
- Добавлен helper `src/genomeai/application/refactor_verify_errors.py`.
- Он изолирует mapping `Exception -> VERIFY_REFACTOR_FAILED` и делает сообщения об ошибках человекочитаемыми без изменения успешного CLI-потока.
- `application/refactor_verify.py` теперь только выбирает команду и делегирует вызов через error-mapping helper.
- Добавлены тесты на `FileNotFoundError`/`ValueError` mapping и стабильный CLI-output для fail-fast ошибок.


## Step 10 — command/dispatch split
- Добавлен `src/genomeai/application/refactor_verify_command.py`: туда вынесены `VerifyRefactorCommand`, `parse_scenarios_arg` и helper выбора сценариев для service-вызовов.
- Добавлен `src/genomeai/application/refactor_verify_dispatch.py`: он собирает `action_name + operation + success_builder` для веток `verify_refactor` и `update_golden`.
- `src/genomeai/application/refactor_verify.py` стал тоньше и теперь только блокирует не подтверждённый `--update-golden`, затем делегирует в dispatch + error-mapping helper.
- CLI и legacy facade `genomeai.refactor_verify` не менялись по поведению.
- Добавлены тесты на command helper, dispatch builder и re-export символов из use-case модуля.

- Step 11: зафиксирован публичный API verify-слоя через явные `__all__` и пакетные re-export'ы в `src/genomeai/application/__init__.py`; добавлены тесты на стабильность import-surface без изменения поведения CLI/Golden.
