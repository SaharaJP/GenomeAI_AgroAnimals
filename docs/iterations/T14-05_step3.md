# T14-05 — Feedback loop, step 3

Дата: 2026-03-10

## Что завершено

- Доведены до рабочего состояния фильтры feedback API по `scoring_run`, `report_version`, `feedback_source`, `model_version`.
- Исправлен сбор training-ready feedback dataset при пустом/NA `task_status` (`pd.NA` больше не ломает расчёт `task_outcome_label`).
- Завершена интеграция feedback loop в Copilot fact-pack и source-only ответы на вопросы вида:
  - «почему отклоняют рекомендации ...»
  - «покажи feedback по scoring_run ...»
- Для feedback-вопросов Copilot теперь остаётся в single-tool маршруте `query_tasks`, если вопрос не содержит явной команды на multi-intent (`что делать` / `сколько стоит`).
- `assistant_knowledge.feedback_loop` признан primary evidence для RAG-ответов, поэтому feedback summary рендерится как подтверждённый факт, а не как missing-data fallback.
