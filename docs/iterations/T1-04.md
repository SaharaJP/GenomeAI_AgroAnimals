## Что добавлено

- Streamlit страница Vet: `streamlit_app/pages/4_Vet_Health_v2.py`

- Тесты: `tests/test_dashboard_vet.py`

## Источники данных

1) Каноника (CSV) из `input_dir` (задаётся в UI):
- `dm_animals.csv`
- `dm_health_events.csv`
- `dm_treatments.csv`
- `dm_alerts.csv` (опционально; для risk-алертов)

2) QC v2 артефакты (из `artifacts_dir`, по `data_version`):
- `artifacts/qc2/<data_version>/<qc_run>/qc_issues.csv`
- `artifacts/qc2/<data_version>/<qc_run>/alerts_auto.csv`

## Withdrawal

- Расчёт выполняется **только в offline-core** по конфигу `configs/health/withdrawal_rules.yaml`.
- Дашборд не ставит диагнозы и не генерирует «болезнь от ИИ».
- В UI показываем:
  - `withdrawal_end_date_effective` (приоритет: явное значение из источника `withdrawal_end_date`, иначе расчёт)
  - `withdrawal_end_date_calc` (прозрачный расчёт по правилам)
  - `withdrawal_mismatch` (если источник и расчёт расходятся)

Подробности: `docs/health/withdrawal_rules.md`.

## Экспорт

Кнопка на странице Vet вызывает `export_vet_registries()` и формирует XLSX в:
`artifacts/<data_version>/runs/<run_id>/dashboards/vet_health_v2/vet_registries.xlsx`

Внутри XLSX:
- `health_events`
- `treatments`
- `active_withdrawal_animals`
- `inspection_list`
- `alerts_health_risk`
- `qc_alerts_auto`
- `qc_issues`
