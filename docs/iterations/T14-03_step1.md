# T14-03 — шаг 1: детерминированный weekly plan generator + draft persistence

## Что сделано
- Добавлен новый offline-core модуль `genomeai.copilot_weekly_plan` для генерации weekly plan только из `copilot_fact_pack`.
- Поддержан пользовательский сценарий вопроса `Сформируй план на неделю`: `answer_question_rag()` детерминированно возвращает 5–15 action items с inline-цитатами, ожидаемым эффектом и source-only disclaimer.
- Добавлены web/API точки создания draft-плана из фактов: `POST /api/weekly_plans_v1/generate` и `POST /weekly_plans/generate`.
- Сгенерированный draft сразу сохраняется в существующий `weekly_plans_v1`, поэтому текущий approval workflow и автоматическое создание задач после approval продолжают работать без переписывания модели.
- В `action_items_json` weekly plan теперь сохраняются дополнительные поля `expected_effect`, `citations`, `source_run_ids`; detail-страница плана показывает expected effect и кликабельные источники по каждому пункту.
- Добавлен audit `weekly_plan.generate` с `data_version`, source run refs и количеством пунктов плана.

## Почему это локальный рефактор
- Не меняется граница `web-cabinet -> offline-core`: web только вызывает генератор и сохраняет draft.
- Не меняется физическая схема weekly plans/tasks; используется существующий JSON payload и уже готовые approve/reject/archive операции.
- Не ломаются существующие сценарии ручного создания weekly plan и старые тесты T12-04.
