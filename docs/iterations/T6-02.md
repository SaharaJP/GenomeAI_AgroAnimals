# T6-02 — Mating plan v1 (decision-support)

## Что сделано

1) Offline-core пайплайн `genomeai.mating_plan_v1`:
   - выбирает коров-кандидатов (по умолчанию: последний `repro_run` T5-01 worklist типов `insemination`/`repeat`;
     fallback: все не-M животные из `dm_animals`);
   - считывает быков из `dm_bulls` и продуктивность коров из `dm_lactations` (best-effort);
   - применяет ограничения по родству из `T6-01` (`inbreeding_constraints.csv`);
   - ранжирует быков по простому скорингу EBV (удой/жир/белок/SCC/цена) с усилением веса под потребности коровы;
   - генерирует `mating_plan.csv` + `mating_plan.xlsx` + `summary.json`.

2) Guard: в UI/скриптах запрещённая пара не может быть подтверждена (`is_pair_allowed`).

3) UI (Streamlit) страница `Подбор пар v1`:
   - просмотр рекомендаций;
   - подтверждение/override и запись в `decision_log_v2`.

## Форматы данных

### Входы

- `artifacts/<data_version>/canonical/dm_animals.csv`
  - используется `animal_id`, `farm_id`, `sex` (если есть), а также `sire_animal_id`, `dam_animal_id` для ограничений (через T6-01).
- `artifacts/<data_version>/canonical/dm_bulls.csv`
  - EBV-поля best-effort: `ebv_milk`, `ebv_fat`, `ebv_protein`, `ebv_scc`, `dose_price`, `available`.
- `artifacts/<data_version>/canonical/dm_lactations.csv`
  - latest lactation per-cow: `calving_date`, `milk_305d_kg`, `scc`.
- `artifacts/<data_version>/pedigree/<pedigree_run>/inbreeding_constraints.csv`
  - таблица разрешённых/запрещённых пар (T6-01).

### Выходы

`artifacts/<data_version>/mating_plan/<mating_plan_run>/`:
- `mating_plan.csv` — long-формат (cow_id, bull_id, rank, score, reasons, confidence)
- `mating_plan.xlsx` — для пользователей (wide+long, cows, bulls, meta)
- `summary.json`, `checksums.sha256`

## CLI

```bash
python -m genomeai.cli mating-plan --data-version <dv> --artifacts artifacts
```

## Ограничения v1

- Нет оптимизации по стаду: ранжирование независимое по коровам.
- Если пара отсутствует в таблице ограничений — считаем запрещённой.
- Качество зависит от полноты EBV/продуктивности в источниках.
