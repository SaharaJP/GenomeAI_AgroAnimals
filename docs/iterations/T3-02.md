# Итерация T3-02 — витрины time-series (cow_day / group_day)

## Что добавлено

1) Offline-core модуль построения витрин `cow_day` и `group_day` (v1).
2) Инкрементальная сборка в пределах одного `marts_run` (добавление новых дат без дубликатов).
3) Явные правила пропусков (dense grid + short-gap ffill до 3 дней) с флагами imputation.
4) Lineage manifest (`lineage_manifest.json`) фиксирует источники, ключи, правила join/aggregation и пропусков.
5) CLI команда `genomeai marts-ts`.
6) Тесты на сборку и инкрементальность.

## Артефакты

Пишутся в `artifacts/<data_version>/marts/<marts_run>/`:
- `cow_day.pkl` + `cow_day.csv`
- `group_day.pkl` + `group_day.csv`
- `lineage_manifest.json`
- `summary.json`
- `checksums.json`

Отдельно создаётся `artifacts/<data_version>/runs/<marts_run>/run_manifest.json` (совместимо с Target layout).

## Ограничения v1

- Витрины строятся на daily-агрегатах (не сырые секунды).
- `group_day` использует только `pen_id` (без других иерархий групп).
- ffill применяется только как техническая имputation для коротких разрывов и помечается флагами.
