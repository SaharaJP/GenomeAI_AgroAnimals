# T13-01 — Job Runner 2.0 / step 1

## Что вошло
- online-миграция таблицы `jobs` до расширенной схемы Job Runner 2.0;
- единые ref-поля для jobs: `data_version`, `run_id`, `qc_run`, `model_version`, `scoring_run`, `report_version`;
- cancel для `queued` и `running` jobs;
- manual retry для `failed/cancelled` jobs;
- извлечение артефактов из `key=value` логов в `artifacts_json`;
- UI `/jobs` c карточкой job, логом и артефактами.

## Что не вошло
- автоматические ретраи по политике;
- отдельная страница фильтров/поиска очереди;
- отдельный API для лог-стриминга.
