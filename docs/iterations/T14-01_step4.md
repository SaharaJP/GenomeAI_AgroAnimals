# T14-01 — шаг 4: resolver deep-link target в web-cabinet

## Что сделано
- Добавлен offline-core resolver для citation target: парсинг `genomeai://copilot/fact?...`, поиск факта/таблицы/запроса на догрузку данных в `copilot_fact_pack`, сбор связанных sources.
- Добавлен web/API слой:
  - `GET /api/copilot/fact`
  - `GET /copilot/fact`
- HTML-страница resolver показывает:
  - параметры target,
  - найденный факт или таблицу,
  - missing-data request при нехватке данных,
  - ссылки на существующие экраны (`/reports`, `/score`, `/repro`, `/workflow`, `/decisions`, `/playbooks`, `/whatif_scenarios`),
  - доступные download/open ссылки на файлы-источники.
- В нижний блок `Источники/версии` у Copilot добавлен `web_target=/copilot/fact?...`, чтобы citation можно было перевести в экран web-cabinet без ручного парсинга custom scheme.

## Почему это локальный рефактор
- Не меняется существующий pipeline `upload -> qc -> score/train -> report -> dashboards`.
- Не переписываются текущие модули UI; добавлен только новый resolver-экран и API.
- Вся бизнес-логика определения фактов остаётся в offline-core.
