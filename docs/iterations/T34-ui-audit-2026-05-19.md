## 1. Раздел «Основное»

### 🟢 `/dashboard` — Главная
**Backlog:** P1-1 (Брифинг) ✅ + P1-2 (Инсайты→задачи) ✅
**Что есть:** Demo-banner; приветствие; «Требует внимания» (empty-state с эмодзи — приятно); карусель из 5 инсайтов с benchmark-сравнением «72% / 48%»; лента событий с фильтром по типу + кнопкой «Добавить событие»; «Данные для изучения» — 3 KPI карты с графиками; inline ask-farm с пресет-вопросами.

**Плохо:** мало real-time индикации (timestamp «брифинг сгенерирован 19 мая 06:00» — статично).

### 🟢 `/daily-summary` — Брифинг
**Backlog:** P1-1 ✅
**Что есть:** AI-сгенерированный заголовок («Требуется внимание: активные протоколы…») + текст с фактическими цифрами; 3 раскрывающихся блока: «За ночь», «Требует внимания», «На заметку»; кнопка «Согласовать и поставить задачи»; настройка расписания (modal) + история.
**Хорошо:** живой LLM-вывод с числами (3 мастита, 3 хромоты, индекс здоровья 18 +4), accordeon-структура, явный workflow «прочитал → согласовал → задачи поставлены».
**Плохо:** только один свежий брифинг видим, история отдельным модалом.

### 🟢 `/insights` — Инсайты
**Backlog:** P1-2 ✅
**Что есть:** 11 активных инсайтов с severity-badge (Срочно/Высокий/Предупреждение/Инфо), 3-таб состояний (К проверке/В работе/Закрыто), кнопка «Сканировать сейчас», «Настройка инсайтов», пагинация (1/2), нижний регион «Рекомендованные задачи» с 11+ карточками.
**Хорошо:** живые AI-инсайты с цифрами (ID 4821 Звёздочка: -22% надой; ID 3142 Ночка: СКК 450k); deep-link на карточку через `/insights/INS_001`.
**Плохо:** колонка «Действия» в таблице — текст-кнопка, не открывает modal; SSE-stream insights работает (видно по логам backend), но в UI нет визуального индикатора нового события.

### 🟡 `/analytics` — Аналитика
**Backlog:** не отдельный эпик, baseline инструмент.
**Что есть:** 3 графика на дашборде + кнопка «Добавить график на эту панель».
**Хорошо:** «лего»-композиция дашбордов.
**Плохо:** конкретные графики не подписаны в snapshot (только generic-контейнеры) — пользователю надо догадаться что именно показано. Стоит добавить заголовок над каждым графиком.

### 🟡 `/timeline` — Лента событий
**Backlog:** связан с P1-2.
**Что есть:** заголовок + текст-описание + кнопка «Скачать архив инструкций»; внутри — два generic-блока (фильтры/события).
**Хорошо:** обещание архива инструкций.

## 8. Cross-cutting наблюдения

### Хорошо в целом
1. **Дизайн консистентен**: одна tabs-компонента, MetricCard, kv-list, DataTable — повторно используются.
2. **Принципы «backend-only logic, React renders evidence»** явно прописаны в info-блоках на нескольких страницах — приятно для аудита.
3. **Empty-states содержательные** — не «нет данных» а «добавьте через POST /api/app/v1/personnel, UI в P1-5».
4. **AI-выходы видны** (Инсайты, Брифинг с цифрами, evidence в карточке коровы).
5. **Demo-banner** на dashboard честно говорит про тестовые данные.

### Плохо в целом
1. **Несоответствия backlog'а реальности** — P1-4 ✅ но пусто, P1-6 ✅ но 500. Backlog нужно скорректировать или допилить.
2. **Loading-плейсхолдеры зависают** на /reproduction, /vet. Нет error-boundary с retry-кнопкой.
3. **Mix EN/RU** — «Account details», «Weekly Farm briefings», «Powered by Copilot» в русскоязычном UI.
4. **Slow timeouts**: `/admin/integrations` тратит ~30 сек до выдачи HTTP 500 (вместо мгновенного 500).
5. **На сценариях** `/economics → Сценарии` — 12 одинаковых «Scenario A draft». Видимо тестовые seed-данные с дублями.
6. **`/copilot`** — только Briefing, нет полноценного chat-UI с ask-farm (он в widget на dashboard inline). Несогласованность ожиданий.
7. **Дублирование контента**: лента событий на /dashboard почти полностью повторяет /timeline. Стоит сделать /dashboard короче, /timeline — полнее.
