# T14-05 — step 1

## Scope
Первый инкремент feedback loop: append-only storage, API, базовый UI accept/reject, метрики и экспорт feedback dataset без реального дообучения.

## Что добавлено
- `src/genomeai/feedback_loop.py` — offline-core функции валидации, сборки feedback dataset и расчёта метрик.
- `web_cabinet/feedback_v1.py` — thin wrapper над web.db: запись feedback, список, метрики, экспорт.
- `web_cabinet/db.py` — таблица `feedback_events_v1` + append-only triggers.
- `web_cabinet/app.py` — API:
  - `POST /api/feedback_v1`
  - `GET /api/feedback_v1`
  - `GET /api/feedback_v1/metrics`
  - `GET /api/feedback_v1/export.csv`
  - `GET /api/feedback_v1/config`
- `streamlit_app/pages/5_Alert_Center_v2.py`, `15_Animal_Profile.py`, `12_AI_Assistant_RAG.py` — формы accept/reject recommendation с reason code.
- `streamlit_app/pages/23_Feedback_Loop.py` — витрина метрик и экспорт feedback dataset.
- `configs/feedback/reason_codes.yaml` — config-driven reason codes и default window.

## Что НЕ закрыто в этом шаге
- Нет реального re-train / recalibration.
- Нет отдельной Jinja/FastAPI HTML-страницы feedback в web-cabinet; UI пока в Streamlit.
- Нет сложной causal/outcome attribution; outcome задач — best-effort join.
