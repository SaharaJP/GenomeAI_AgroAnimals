# T14-01 — шаг 5: кликабельные citation links в UI и быстрые переходы к preview

## Что сделано
- Добавлен shared helper `copilot_ui_links.py`, который строит карточки для UI по цитатам Copilot: resolver/open, preview таблицы, jobs по run_id, reports по data_version, JSON API.
- Streamlit-страница `12_AI_Assistant_RAG.py` теперь рендерит кликабельные переходы рядом с ответом ассистента вместо ручного копирования `web_target` из текста.
- Web resolver `/copilot/fact` усилен блоком `Быстрые переходы`, якорями `#fact-card/#table-preview/#missing-data/#artifacts` и кликабельными ссылками для related facts/tables.
- API `GET /api/copilot/fact` теперь возвращает `detail_actions`, чтобы любой UI-слой мог отрисовать те же переходы без дублирования логики.

## Почему это локальный рефактор
- Не меняется расчётный offline-core и не затрагивается pipeline `upload -> qc -> score/train -> report -> dashboards`.
- Web/Streamlit по-прежнему только отображают ссылки и вызывают resolver/артефакты, не считают факты сами.
- Новый конфиг ограничен UI-параметрами (`web_base_url`, `show_citation_cards`, `max_citation_cards`) и имеет безопасные дефолты.
