# T2-03 — Task/Worklist v1

## Что такое task (v1)
`tasks_v1` — простой список действий, производный от алертов/правил. Это **не** таск‑трекер.

## Статусы (минимум)
- `open` — создано
- `in_progress` — взято в работу
- `done` — выполнено
- `cancelled` — отменено (не выполнено)

## Связи
- `related_alert` — ссылка на `alerts_v2.alert_id` (если задача создана из алерта)
- При закрытии задачи:
  1) пишется запись в **Decision Log v2** (`decision_log_v2`) с `action="task.close"` (append-only)
  2) если `related_alert` заполнен и задача закрыта со статусом `done`, то связанный алерт переводится в `resolved`

## Единый формат решения
Решение при закрытии задачи всегда пишет поля трассировки:
- `data_version`, `model_version`, `report_version` (+ `qc_run`, `scoring_run` при наличии)
- `object_type/object_id` и `related_alert`

## Источники генерации v1
В v1 реализовано авто‑создание **из alerts_v2** по каталогу `configs/tasks_v1/catalog.yaml`.
Дедупликация: `dedupe_key = "alert:<alert_id>|task:<task_type>"` для активных задач (`open/in_progress`).
