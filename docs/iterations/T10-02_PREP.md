# T10-02 — PREP (инициализация итерации)

## Контекст
В репозитории уже реализован MVP+ и итерация **T10-01** (IA v3 + ролевые Home + smoke).
Эта PREP-заметка фиксирует текущее состояние и рамки для **T10-02** до получения точного промпта.

## Базовая проверка состояния (выполнено)
1) Установка в editable режиме: `pip install -e .`
2) Прогон тестов: `pytest -q`
