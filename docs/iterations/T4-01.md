# T4-01 — Модель данных здоровья/лечений + withdrawal

## Цель

Сделать однозначную, проверяемую спецификацию и проверки для:
- `dm_health_events` — факты событий здоровья
- `dm_treatments` — факты лечений
- withdrawal — детерминированный расчёт окна ограничений

Ограничение: никаких диагнозов «от ИИ». Только факты + правила.

## Что сделано

1) Добавлены контракты данных для `dm_health_events` и `dm_treatments`.
2) Добавлены справочники (коды) типов событий и типов лечений.
3) Обновлён QC v2:
   - совместимость ключей правил (`child_col`/`parent_col` и т.п.)
   - реализован `join_date_order` (используется в текущем каталоге правил)
   - добавлены правила здоровья/лечений (обязательность полей, дат, FK, overlap, allowed values)
4) Уточнено правило withdrawal (окно считается включительно по дате окончания).

## Источники данных

- `dm_health_events.csv`, `dm_treatments.csv` в input/canonical слоях.
- Правила withdrawal: `configs/health/withdrawal_rules.yaml`

См. `docs/health/withdrawal_rules.md`.
