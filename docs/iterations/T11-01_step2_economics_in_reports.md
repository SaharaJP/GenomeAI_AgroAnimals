# T11-01 Step2 — Economics 2.0: интеграция в шаблонные отчёты + детализация формул в UI

## Что сделано

1) Добавлен новый раздел шаблонного отчёта: `economics`.
2) Раздел `economics` читает витрину `artifacts/<data_version>/economics_v2/<economics_run>/economics_daily.csv` (последний запуск) и выводит срез на дату `<= asof_date`.
3) Поддержан фокус `farm/site/pen` (для `animal` экономика не выводится: в T11-01 считаем только по ферме/площадке/группе).
4) В `Trace` шаблонного отчёта добавлены версии `economics_run/date_selected` для сквозной воспроизводимости.
5) В UI `Экономика 2.0` расширена расшифровка: показываем каталог формул, компоненты с уже посчитанными значениями, входные переменные и источники цен.

## Проверка вручную

1) Посчитать economics_v2 (страница **19_Economics_v2**) и убедиться, что появился `economics_run`.
2) Открыть **18_Report_Templates** → добавить секцию `economics` в шаблон → сгенерировать отчёт.
3) В **16_Report_View** открыть `report_version` и убедиться, что раздел `Economics (RUB)` присутствует.
