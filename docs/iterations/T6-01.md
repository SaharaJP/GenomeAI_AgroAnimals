# T6-01 — Pedigree QC + инбридинг-ограничения (v1)

## Цель
Сделать проверяемый, объяснимый офлайн-модуль, который:
1) проверяет качество родословной (`dm_animals`),
2) строит ограничения по общим предкам до `N` поколений (без геномики),
3) генерирует алерты о проблемах качества pedigree.

## Входные таблицы
- `dm_animals.csv` (обязательная): `farm_id`, `animal_id`, `sire_animal_id`, `dam_animal_id`, опционально `sex`.
- `dm_bulls.csv` (опциональная): `farm_id`, `bull_id`.

## QC проверки (правила v1)
Результат пишется в `qc_issues.csv`.

### PED.MISSING_PARENTS_FARM
**Что:** на уровне фермы считаем долю пропусков `sire_animal_id` и `dam_animal_id`.
**Порог:** `qc.missing_parent_pct_warn` из `configs/pedigree/pedigree_rules_v1.yaml`.
**Почему важно:** неполнота ухудшает контроль инбридинга и качество подбора пар.

### PED.UNKNOWN_PARENT_REF
**Что:** `sire_animal_id` или `dam_animal_id` указан, но такого `animal_id` нет в `dm_animals`.
**Замечание:** токены неизвестного родителя нормализуются по списку `unknown_parent_tokens`.

### PED.DUPLICATE_CONFLICT
**Что:** дубликаты `animal_id` в одной ферме с разными `sire/dam`.

### PED.SELF_PARENT
**Что:** `animal_id == sire_animal_id` или `animal_id == dam_animal_id`.

### PED.CYCLE
**Что:** цикл в графе родословной (животное является своим предком).
**Алгоритм:** DFS с recursion-stack на графе «ребёнок → родители».

## Инбридинг-правило (v1)
Результат пишется в `inbreeding_constraints.csv`.

### Правило запрета
Пара `(cow_id, bull_id)` запрещена, если пересечение множеств предков (до `N` поколений) непустое.
- `N = inbreeding.generations` (или CLI `--generations`).
- В отчёт кладём до `inbreeding.max_common_ancestors_list` общих предков.

### Деградация при неполноте
- Если `bull_id` отсутствует в `dm_animals`: ограничения считаются с `confidence=LOW`.
  Поведение по умолчанию — **разрешить** (см. `inbreeding.allow_if_bull_missing_pedigree`).

## Алерты
Модуль пишет `alerts_auto.csv` (формат совместим с Alert Center v2).
Типы алертов добавлены в `configs/alerts_v2/catalog.yaml`:
- `PEDIGREE.MISSING_PARENTS`
- `PEDIGREE.UNKNOWN_PARENT_REF`
- `PEDIGREE.CONFLICT`
- `PEDIGREE.CYCLE`

## Артефакты
`artifacts/<data_version>/pedigree/<pedigree_run>/`:
- `qc_issues.csv`
- `alerts_auto.csv`
- `inbreeding_constraints.csv`
