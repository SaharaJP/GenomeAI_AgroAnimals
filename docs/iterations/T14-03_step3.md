# T14-03 — step 3

## Что сделано
- Добавлена director queue `pending approval` для weekly plans в offline-core/web-cabinet.
- Добавлен API `GET /api/weekly_plans_v1/pending_approval` с summary по плану: item_count, citation_count, source_run_ids, approval requester.
- На странице `/weekly_plans` для ролей с `weekly_plans.approve` добавлен блок **Планы на approval**.
- В Streamlit Copilot добавлены прямые действия директора: approve, reject, export PDF по pending weekly plan.
- PDF meta расширен полями approval/request summary и агрегированными citations/source_run_ids из action items.
- Повторный request_approval теперь сбрасывает rejection-поля; rejected draft исчезает из pending queue до повторной отправки.
