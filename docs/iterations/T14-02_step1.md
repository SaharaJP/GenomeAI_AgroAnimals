# T14-02 — шаг 1: tooling API + deterministic routing + RBAC foundation

## Что сделано
- Добавлен новый offline-core модуль `src/genomeai/copilot_tools.py` с детерминированной маршрутизацией вопроса в один из tools: `query_kpi`, `query_anomalies`, `query_tasks`, `query_economics`.
- Введён конфиг `configs/copilot/tools_v1.yaml`: required permission, section-prefixes fact-pack и keyword-правила маршрутизации без массового рефактора существующего Copilot.
- `answer_question_rag()` теперь принимает `user_role` и `user_permissions`, вызывает tool-router, фильтрует `copilot_fact_pack` по выбранному tool и пишет audit-событие `assistant.copilot.tool_route`.
- При нехватке прав Copilot отвечает человекочитаемо: какой tool был выбран и какой permission нужен.
- В `build_fact_pack_for_assistant()` добавлен блок `assistant_knowledge.tasks_v1`, чтобы tool `query_tasks` мог работать на данных из `web.db`.
- Streamlit UI ассистента начал прокидывать роль и permissions пользователя в offline-core.

## Почему это локальный рефактор
- Не меняются pipeline `upload -> qc -> score/train -> report -> dashboards` и существующие артефакты модулей.
- Tool-layer работает поверх уже существующего `copilot_fact_pack`, а web-cabinet по-прежнему не считает факты сам.
- Конфиг и новый модуль изолированы; старые вызовы `answer_question_rag()` остаются совместимыми благодаря опциональным параметрам.
