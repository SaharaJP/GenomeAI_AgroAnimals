# T14-02 — шаг 3: explain/recommend/cost templates + detail-level RBAC for citation targets

## Что сделано
- В `ai_assistant_rag.py` добавлены tool-специфичные source-only шаблоны ответов для сценариев `query_anomalies/why`, `query_tasks/what_to_do`, `query_economics/cost`.
- Ответы остаются строго воспроизводимыми: используются только подтверждённые fact/table chunks, preview строк таблиц и playbook/task контекст из fact-pack.
- Для `what_to_do` Copilot теперь выводит конкретные строки задач (`task_id/title/status/priority/object_id/...`) и, при наличии прав, дополняет их playbook-контекстом.
- Для `why` и `cost` Copilot формирует более полезный объясняющий шаблон без LLM-фантазий: «сигналы/выборки/что проверить» и «подтверждённая экономика».
- В web/API resolver добавлен detail-level RBAC: `/api/copilot/fact` и `/copilot/fact` проверяют permission по целевому `section` и отказывают с `403 copilot_target_forbidden`, если раздел недоступен роли.
- В Streamlit citation cards скрывают ссылки на экраны, требующие дополнительных прав (`reports/playbooks/whatif`), чтобы UI не предлагал заведомо недоступные переходы.

## Почему это локальный рефактор
- Не меняются run-артефакты, факт-пак и граница `web -> offline-core`.
- Логика ограничена слоем Copilot answer rendering и resolver security-check, без переписывания existing dashboards/jobs/reports.
- RBAC использует уже существующую permission-модель и config-driven mapping из `tools_v1.yaml`.
