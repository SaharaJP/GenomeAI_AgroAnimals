# ML validation (A3)

## Цель

Для baseline-модели продуктивности (таргет: `dm_lactations.milk_305d_kg`) используется валидация без утечек, учитывающая время (год/сезон отёла).

## Принцип split (anti-leakage)

Мы не перемешиваем наблюдения случайно, потому что тогда модель могла бы "видеть будущее" через сезонность/тренды.

Алгоритм split:

1. **Year holdout (предпочтительно):**
   - если в данных есть как минимум 2 разных `calving_year`, то **весь последний год** (max `calving_year`) используется как test.
   - train = все годы < test_year.
   - если при таком split получается слишком мало строк (train < 20 или test < 10), включается fallback.

2. **Fallback: time percentile:**
   - сортируем по (`calving_year`, `calving_quarter`) и берём последние 20% как test.

Split фиксируется в `model_card.json`/`train_summary.json`.

## Ограничения

- Признак **age_at_calving** считается только если в каноническом слое доступен `dm_animals.birth_date` и он успешно парсится.
- Если `birth_date` отсутствует/пустой для всех строк — признак пропускается, а причина фиксируется в model card.
