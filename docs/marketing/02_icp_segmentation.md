**Дата:** 2026-05-19
**Основание:** 12 глубинных интервью (CustDev N=12, см. `01_customer_discovery_evidence.md`)
**Статус:** рабочая гипотеза, требует уточнения по итогам первых demo

## Введение: почему три сегмента, а не один

В 12 интервью обнаружилось три разные модели принятия решений и три разных болевых профиля. Продавать одинаково — значит плохо продавать всем трём. Здесь — описание каждого сегмента и рекомендация, с какого начинать.

---

## Сегмент A: «Современная средняя ферма»

### Профиль

| Параметр | Значение |
|---|---|
| Поголовье | 200–500 коров |
| Форма собственности | ООО/ИП, один объект |
| Регионы | Центральный, Северо-Западный, Беларусь |
| Текущий стек | Селэкс или Плинор + Excel + доильный зал (DeLaval / GEA / Boumatic) |
| Выгрузка данных | частично: Селэкс ведётся, Excel — ручной |
| Цифровой зрелость | средняя: 1С в бухгалтерии есть, данных с фермы нет в единой системе |

### Decision-maker

**Собственник или директор** (принимает решение о бюджете) + **зоотехник** (инициирует запрос, демонстрирует кейс). Оба должны быть «за» — один без другого не закроет сделку.

Типичный директор этого сегмента: 40–52 года, прошёл агроуниверситет или экономику, владеет хозяйством 5–15 лет, смотрит KPI раз в неделю в Excel, хочет «видеть ферму в телефоне» но не знает с чего начать. Типичный зоотехник: 30–45 лет, 200–500 голов «знает в лицо», ведёт тетрадь + Селэкс параллельно, перегружен ежедневными задачами.

### Бюджет на ПО

- **Текущий:** 0–80 000 ₽/год (Селэкс или 1С-лицензия)
- **Готовы рассматривать:** 80 000–200 000 ₽/год при доказанном ROI
- **Комментарий:** сравнивают со стоимостью Селэкса. Аргумент «экономит 158 000 ₽/год только на мастите» закрывает ценовой вопрос на стаде 400 голов

### Типичный стек сегодня

```
Селэкс/Плинор → ручной экспорт в Excel → зоотехник делает сводную
Доильный зал → отдельная программа → данные не стыкуются с Селэксом
1С-Бухгалтерия → учёт расходов → нет связи с производственными KPI
Бумажный журнал → ветеринарные события
```

### Decision criteria

1. **Интеграция с Селэксом без потери текущих данных** — deal-breaker если нет
2. **Конкретный ROI в деньгах** — «сколько сэкономим за год» (не «будет эффективнее»)
3. **Простота внедрения** — зоотехник не должен тратить месяц на перенастройку
4. **Российская поддержка** — «позвоню и мне ответят по-русски сегодня»

### Где искать (каналы)

- **Союзмолоко** — члены союза (список публичный на soyuzmolokoрф)
- **Региональные минсельхозы** — реестры сельхозпроизводителей, доступны по запросу
- **Выставка АгроФерма** (Москва, февраль) — прямой контакт у стендов
- **Milknet.ru** — форум зоотехников, объявления о поиске специалистов дают контакт хозяйства
- **LinkedIn** — редко, но директора среднего сегмента появляются
- **ВКонтакте / Telegram** — профильные группы зоотехников («Молочное животноводство РФ», «Зоотехники России»)

### Trigger-моменты для покупки

- Сменился зоотехник (боль 4: «3 месяца на передачу знаний» — острая боль прямо сейчас)
- Упал надой без объяснения причин (боль 3: «копаем неделю — не найдём»)
- Ветеринарная проверка с замечаниями по документации
- Получили субсидию или грант на цифровизацию от регионального минсельхоза
- Директор съездил на выставку и «увидел как у других»

### Deal-breakers

- Нет интеграции с Селэксом — «мы не будем вводить всё заново»
- Облачное хранение данных стада за рубежом — «не хотим, чтоб наши данные где-то там»
- Требует отдельного ИТ-специалиста для поддержки
- Слишком дорого без пилота — «дайте попробовать»

## Сегмент B: «Холдинг до 1500 голов»

### Профиль

| Параметр | Значение |
|---|---|
| Поголовье | 800–1500 коров, 2–5 ферм в управлении |
| Форма собственности | агрохолдинг или ООО с несколькими объектами |
| Регионы | Центральный, Приволжский, Беларусь (крупные) |
| Текущий стек | 1С-Агро + Селэкс на каждой ферме отдельно, нет единой картины |
| Цифровая зрелость | высокая: есть IT-директор или администратор 1С |

### Decision-maker

**IT-директор или директор по операциям** как инициатор и технический оценщик + **гендиректор холдинга** как финальный подписант. Зоотехник каждой фермы — вето-игрок («если зоотехники против — не купят»).

### Бюджет на ПО

- **Текущий:** 200 000–600 000 ₽/год на весь контур (1С-Агро + разные лицензии)
- **Готовы рассматривать:** 300 000–800 000 ₽/год при кросс-фермерской аналитике
- **Дополнительно:** готовы к пилоту на одной ферме с опцией масштабирования

### Типичный стек сегодня

```
1С-Агро (управленческий учёт, финансы)
Селэкс на каждой ферме отдельно → нет единой базы по холдингу
Отчёты — Excel сводные, которые ИТ-директор собирает руками раз в месяц
```

### Decision criteria

1. **Кросс-фермерская аналитика** — «хочу видеть все 3 фермы в одном дашборде»
2. **Интеграция с 1С-Агро** — не может заменить, только обогатить
3. **SLA и поддержка уровня enterprise** — «у нас не бывает «подождите до понедельника»»
4. **Безопасность данных** — возможность on-premise или частного облака
5. **Пилот на одной ферме** перед масштабированием — стандартная практика

### Где искать

- **Партнёры 1С-Агро** — реселлеры знают своих клиентов-холдингов и могут порекомендовать
- **Выставка «Молочная и Мясная индустрия»** (Москва, март)
- **Союзмолоко** — крупные члены на сайте поимённо
- **LinkedIn** — IT-директора агрохолдингов иногда активны
- **Отраслевые конференции** — «Молочные реки», региональные АПК-форумы

### Trigger-моменты

- Экспансия: открывают новую ферму и понимают что управлять несколькими «по-старому» уже нельзя
- Инвестор или банк требует управленческую отчётность в машиночитаемом формате
- Нанимают нового операционного директора, который «привёз требования» с предыдущего места
- Аудит кормовых расходов не сходится с надоем

### Deal-breakers

- Нет on-premise опции — для холдингов с жёсткой IT-политикой
- Нет API для интеграции с их 1С — «без этого не рассматриваем»
- Невозможно дать разные права разным фермам
- Слишком долгое внедрение — «нам надо за месяц, не за полгода»

## Сегмент C: «Прогрессивная малая ферма»

### Профиль

| Параметр | Значение |
|---|---|
| Поголовье | 150–250 коров |
| Форма собственности | КФХ или ООО, фермер = директор = зоотехник |
| Регионы | любые, часто сельская местность |
| Текущий стек | Excel + бумага; иногда простой учёт в телефоне |
| Цифровая зрелость | низкая: один человек делает всё |

### Decision-maker

**Сам фермер** — принимает решение за 1–2 разговора, без тендера.

### Бюджет на ПО

- **Текущий:** 0–30 000 ₽/год (возможно, ничего)
- **Готовы рассматривать:** 30 000–80 000 ₽/год, если «сразу понятно и работает»
- **Психология:** покупают «за результат», не за «платформу»

### Decision criteria

1. **Простота — запустился сам без консультанта**
2. **Работает на телефоне**
3. **Ценник прозрачный** — без «свяжитесь с отделом продаж»
4. **Виден результат за первые 2 недели** — иначе уходят

### Где искать

- **Telegram-каналы фермеров** — «Фермерская Россия», «КФХ», региональные группы
- **ВКонтакте** — сообщества «Молочное фермерство», «Корова — мой бизнес»
- **Региональные АККОР** (Ассоциация крестьянских хозяйств) — мероприятия, рассылки
- **YouTube** — авторы-фермеры с каналами: партнёрство / упоминание

### Trigger-моменты

- Болезненный случай с коровой, которого «не увидели вовремя»
- Нашли видео или пост о цифровизации в Instagram/VK
- Рекомендация коллеги-фермера

### Deal-breakers

- Нужна интеграция с чем-то (у них нет «чего-то»)
- Длинный онбординг — «у меня нет времени на учёбу»
- Нет мобильного приложения (Android — первый приоритет по нашему roadmap)
- Цена > 80 000 ₽/год — психологический барьер

## MVP-фокус: какой сегмент берём первым

### Рекомендация: Сегмент A — «Современная средняя ферма»

**Обоснование:**

| Критерий | Сегмент A | Сегмент B | Сегмент C |
|---|---|---|---|
| Размер сделки (₽/год) | 120 000–200 000 | 300 000–800 000 | 40 000–80 000 |
| Сложность продажи | средняя | высокая (тендер/IT) | низкая |
| Длина цикла | 4–8 недель | 2–6 месяцев | 1–3 недели |
| Интеграционные требования | Селэкс (готов) | 1С-Агро (в roadmap) | минимальны |
| Референсная ценность | высокая | очень высокая | средняя |
| Масштабируемость дохода | средняя | высокая | низкая |
| Founder-led sales реалистичен | **да** | частично | да |

**Почему A, а не B:** холдинги (B) — более крупный чек, но sales-цикл 2–6 месяцев, нужен IT-пилот, корпоративный контракт. На стадии 0 пилотов это убьёт первые 6 месяцев. Сегмент A: можно закрыть за 4–8 недель founder-led sales, получить референс, перейти к B.

**Почему A, а не C:** малая ферма (C) платит мало, требует мобильного приложения (в roadmap, но не MVP), сложно масштабировать ARR. Использовать C как тест channel'а (партнёрства, Telegram) — да. Как первичный ICP для founder-led sales — нет.

**Вывод:** первые 3 платных пилота — исключительно Сегмент A. После получения 2–3 reference customers из A — открываем Сегмент B.

## Anti-ICP — кого НЕ берём

| Категория | Почему нет |
|---|---|
| Фермы < 150 голов | Unit economics не сходится: чек < 50k₽/год, CAC сопоставим с LTV |
| Фермы > 2000 голов | Требуют enterprise-контракт, безопасность, тендер, длинный цикл. Не для seed-стадии |
| Государственные учебные хозяйства | Бюджетный процесс, нет ROI-мышления, нет скорости |
| Свиноводство / птицеводство | Другая специфика болей, другие данные, нет продуктового фита |
| Фермы без электронного учёта (Excel/бумага только) | Слишком долгий онбординг: нет базы данных для интеграции; отдача через 3+ месяца |
| Фермы в регионах без интернета (Сибирь, Дальний Восток) | On-premise деплой возможен, но поддержка нереалистична на seed-стадии |

## Honest status

`not_proven` — сегментация построена на базе 12 интервью и логике продуктового фокуса. Реальные conversion rate по сегментам станут известны только по итогам outreach (см. `06_gtm_plan.md`) и первых demo. До завершения 6-недельного GTM-эксперимента — это обоснованная гипотеза, а не подтверждённый факт.

**Что валидируется первым:**
- Готов ли Сегмент A платить 120–200k₽/год без долгого тендера (проверяется в demo-разговоре)
- Является ли интеграция с Селэксом реальным must-have или «было бы хорошо» (проверяется на onboarding первого пилота)
- Кто реально подписывает — собственник или зоотехник (проверяется в 5–10 первых звонках)
