# Alert Center v2: каталог типов алертов

Источник истины: `configs/alerts_v2/catalog.yaml`.

## Принципы

1) **Алерты объяснимы**: у каждого типа есть *почему* (`why`) и список шагов *что сделать* (`actions`).
2) **Никаких диагнозов от ИИ**: ...
3) **Генераторы best-effort**: ...

## Группы источников

- `QC` — автоалерты из QC v2 (`artifacts/qc2/<data_version>/<qc_run>/alerts_auto.csv`).
- `ML` — факты/риски из `dm_alerts`.
- `BIZ` — детерминированные бизнес-правила (withdrawal, репродукция, сенсоры).
- `SECURITY` — системные события (опционально; пока типы только каталогизированы).

## Минимальное требование

Каталог содержит **>= 40 типов**. Это проверяется тестом `tests/test_alerts_v2_catalog.py`.
